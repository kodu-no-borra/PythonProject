# API Эндпоинты PythonProject

Проект на Django + DRF с задачами (`Task`). Все эндпоинты доступны по пути `/api/tasks/`.

---

## 1. Список и создание задач

**URL:** `/api/tasks/`  
**Методы:**  
- `GET` — получить список всех задач  
- `POST` — создать новую задачу

**Пример запроса на создание (POST):**

```json
{
  "title": "Первая задача",
  "description": "Описание для теста",
  "status": 1
}
````

**Ответ (POST/GET):**

```json
{
  "id": 1,
  "title": "Первая задача",
  "description": "Описание для теста",
  "status": 1,
  "created_at": "2025-11-10T14:00:00Z",
  "updated_at": "2025-11-10T14:00:00Z"
}
```

---

## 2. Получение конкретной задачи

**URL:** `/api/tasks/<int:pk>/`
**Метод:** `GET`
**Описание:** Получает задачу по её `id` (`pk`).

**Пример запроса:**

```
GET /api/tasks/1/

```

**Ответ:**

```json
{
  "id": 1,
  "title": "Первая задача",
  "description": "Описание для теста",
  "status": 1,
  "created_at": "2025-11-10T14:00:00Z",
  "updated_at": "2025-11-10T14:00:00Z"
}
```

---

## 3. Обновление статуса задачи

**URL:** `/api/tasks/<int:pk>/status/`
**Метод:** `PATCH`
**Описание:** Обновляет только поле `status` задачи.

**Пример запроса:**

```json
{
  "status": 2
}
```

**Ответ:**

```json
{
  "id": 1,
  "title": "Первая задача",
  "description": "Описание для теста",
  "status": 2,
  "created_at": "2025-11-10T14:00:00Z",
  "updated_at": "2025-11-10T14:10:00Z"
}
```

---

## 4. Удаление задачи

**URL:** `/api/tasks/<int:pk>/delete/`
**Метод:** `DELETE`
**Описание:** Удаляет задачу по её `id`.

**Пример запроса:**

```
DELETE /api/tasks/1/delete/
```
